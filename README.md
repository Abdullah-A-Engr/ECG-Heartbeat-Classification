# Results directory

`example_beats.png`, the dataset summary, class-count table, and gradient-check values were generated from the supplied CSV archives. Full three-learning-rate training was started in the available CPU environment but did not complete within the execution window. Therefore, no final selected learning rate, best 30-epoch checkpoint, test metrics, or confusion matrix is claimed here. Run `python src/train.py` to completion, followed by `python src/test_model.py`, to generate these items.
