I’m sharing our Applied Machine Learning project: ECG Heartbeat Classification using a neural network built and trained from scratch in PyTorch.

The project classifies ECG beat segments into five categories. We implemented the network parameters, softmax cross-entropy, gradient verification, and a manual minibatch training loop with momentum and weight decay. We also developed a Streamlit interface to visualize a beat and inspect the model's predicted class scores.
